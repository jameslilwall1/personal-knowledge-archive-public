# Knowledge Archive - releases

Public release channel for Knowledge Archive, a private archive of one person's own documents.
The source lives in a private repository, and no archive content is ever here: this repo exists
only to host the Windows installer and the metadata the app's auto-updater reads.

Download the latest `Setup` installer from the
[Releases](https://github.com/jameslilwall1/personal-knowledge-archive-public/releases) page.
Installed copies check for updates themselves and download one only when asked.
